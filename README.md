## Descripción del programa

Este programa consiste en un sistema de inventario para una tienda desarrollado en Python utilizando programación orientada a objetos.

El sistema permite administrar productos mediante un menú interactivo donde se pueden agregar productos, vender productos, mostrar el inventario y encontrar el producto con mayor precio.

## Funcionalidades del programa

### 1. Agregar producto
Permite ingresar un producto al inventario solicitando su nombre, precio y cantidad disponible.

También valida que el precio y la cantidad sean mayores que cero.

### 2. Vender producto
Permite realizar la venta de un producto registrado, disminuyendo la cantidad disponible en el inventario.

Verifica que exista suficiente cantidad del producto antes de realizar la venta.

### 3. Mostrar inventario
Muestra todos los productos registrados con su nombre, precio y cantidad disponible.

### 4. Producto más caro
Busca y muestra el producto que tiene el precio más alto dentro del inventario.

### 5. Salir
Permite finalizar la ejecución del programa.
